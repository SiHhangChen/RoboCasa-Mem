# TM04

TM04 is the three-thread extension of TM02. It interleaves pot filling, can
retrieval, and an exactly-two-of-three sugar-count thread.

The simulator-free contract, twelve-route expert expansion, combined layout-15
scene, unified physical observer, and hybrid manipulation runtime are
implemented. Water/cabinet/can execution inherits TM02's validated layout-15
resources, while TM04 owns the calibrated sugar and saucepan stations.
The can release marker is isolated on the counter to the right of the sink;
the sugar tray remains beside the stove and no longer shares that workspace.

The fixed seed-0 expert route has been physically validated end to end: all 31
stages complete, exactly two of three sugars finish in the saucepan, and the
completion-button success contract passes.

Package layout version: `membench.task_package/v1`.
