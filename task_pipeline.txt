具体流程如下：

  1. 初始状态
     机器人站在咖啡机前，有两杯已经做好的咖啡，还有一个盘子放了糖块，场景里有：
     coffee_A、coffee_B 两个相同杯子，sugar_plate，sugar_cube，coffee machine，dining counter。

  2. 拿起糖块
     pick_sugar

  3. 把糖放进 coffee_A
     place_sugar，目标 receptacle 是 coffee_A

  4. 应用 sugar proxy
     apply_sugar_proxy
     这里会把糖视为已经进入 coffee_A，然后隐藏糖块。状态变成：
     sugared_coffee_id = "coffee_A"
     unsugared_coffee_id = "coffee_B"
     sugar_consumed = True

  5. 随机选择一杯coffee送到 dining counter

  6. 回去拿另一杯 coffee

  7. 两杯必须在 dining counter 上且距离足够近
     _cups_together_on_dining_counter() 要满足：
     coffee_A_on_dining_counter == True
     coffee_B_on_dining_counter == True
     两杯 XY 距离 <= together_threshold，默认 0.22

  8. 最后选择加糖的那杯
     select_sugared_coffee，当前固定选择 coffee_A

     以机器人站在放杯站位、面向水槽为视角，当前 Base yaw 接近 0°，因此世界坐标基本对应：

                       前 / 水槽
                         +X
                          ↑
                          |
  左 / +Y   ←─────────────┼─────────────→   右 / -Y
                          |
                          ↓
                         -X
                       后 / 机器人

  1. 新建一个命名会话

  tmux new -s pi05
  （pi05 是会话名，方便以后找回）

  2. 在会话里启动训练

  进入会话后（你现在已经在里面了），运行：
  cd /home/chensihang/membench
  scripts/train/pi05/train_pi05_wa01.sh
  此时你会看到 loss 实时打印：
  Step 0: grad_norm=0.6608, loss=0.2226, param_norm=1803.7705
  Step 10: grad_norm=0.62, loss=0.21, ...

  3. 分离（关键一步）→ 训练在后台继续

  按快捷键：Ctrl-b 然后 d（先按 Ctrl-b 松开，再按 d）
  你会回到普通终端，屏幕上提示 [detached]，训练继续在后台跑。

  4. 随时回来查看

  tmux attach -t pi05        # 重连会话，看到实时 loss
  tmux ls                    # 列出所有会话

  5. 结束训练

  回到会话里，等它自然跑完；想中途停就 Ctrl-c；整个会话删掉：
  tmux kill-session -t pi05
